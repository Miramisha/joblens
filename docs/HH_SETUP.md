# Вакансии hh.ru в JobLens

## Текущий статус

В кабинете https://dev.hh.ru/admin при регистрации приложения указано прекращение поддержки API для соискателей с 15 декабря 2025 года. Форма предлагает только приложения работодателей. JobLens не отправлял заявку с неверным типом пользователя. Новое подключение личного профиля отключено: `/api/hh/connect` возвращает 410. Сохранённые ранее подключения можно удалить в аккаунте; данные вакансий не удаляются. Старые таблицы и код проверки/отзыва токенов сохранены для совместимости, без автоматического импорта откликов.

## Поиск и добавление

На доске кнопка «Вакансии hh.ru» открывает поиск по должности и загрузку по ссылке `https://hh.ru/vacancy/<id>`. Нужен вход в JobLens. Поддомены hh.ru поддерживаются, посторонние адреса, порты и учётные данные в URL отклоняются. Сервер обращается только к фиксированному `https://api.hh.ru`, не следует перенаправлениям и не передаёт ему пользовательские cookie или секреты Resend.

Полученная вакансия открывается в обычной форме: компания, должность, регион, зарплата, описание и навыки. HTML превращается в текст; скрипты не исполняются. Поля ограничены лимитами JobLens. Перед сохранением пользователь проверяет данные. Повторный импорт той же вакансии открывает существующую карточку; в поиске уже добавленные вакансии помечены. Этапы отмечаются вручную и учитываются существующей аналитикой.

## Ограничение внешнего API

Живые запросы поиска и просмотра в проверенной среде получили HTTP 403 `forbidden`, хотя справочник `/areas` доступен. Причина отказа конкретному запросу не раскрыта. Спецификация поиска предупреждает о капче после первого запроса без токена. Наличие документации анонимного метода не гарантирует постоянный доступ с сервера JobLens.

При 401/403 интерфейс сообщает об ограничении, при 429 предлагает подождать; удалённые и архивные вакансии не импортируются автоматически. Есть ссылка на поиск hh.ru и переход к ручному заполнению. Обход капчи или ограничений не реализован. Успешную живую загрузку вакансии подтвердить пока не удалось; обработка успешного ответа проверена на тестовых данных. Это подготовленная интеграция с явным ограничением провайдера, а не гарантированная работающая синхронизация.

Настройка заголовка приложения — `HH_USER_AGENT`. Не заменяйте существующий `.env` целиком и не публикуйте секреты. Клиентские ключи hh.ru не требуются для попытки анонимного запроса. Ключи приложения работодателя не дают права выдавать JobLens за приложение работодателей.

Источники: [форма регистрации](https://dev.hh.ru/admin), [официальная спецификация](https://api.hh.ru/openapi/specification/public), [документация вакансий](https://github.com/hhru/api/blob/master/docs/vacancies.md).

## Проверки

`pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`. Тесты `hh-vacancies.test.ts` проверяют URL, ограничения полей и безопасное преобразование описания. `account-hh-smoke.py` проверяет аккаунт, отключение старого OAuth, авторизацию и отклонение некорректных ссылок без запросов во внешний API. Запуск изолированного сервера описан в [EMAIL_AUTH_SETUP.md](EMAIL_AUTH_SETUP.md).
