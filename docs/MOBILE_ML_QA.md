# Мобильная проверка и подключение ML — 23 сентября 2026

Проверка в браузере с изменением viewport, не на физических iOS/Android устройствах.

- 320 px: доска, аналитика, создание/редактирование карточки, окно CSV, окно hh.ru, профиль и раскрытие формы резюме.
- 390 px: доска и карточка с результатами ML; 430 px: карточка и неопределённый результат.
- 1280 px: контроль ширины доски после изменений.
- Найдено переполнение профиля (342 px при viewport 320 px) из-за поля выбора файла резервной копии. После ограничения ширины — 320/320.
- Поля карточки на мобильных увеличены с 14 до 16 px; кнопка закрытия имеет область 44 px, нижние кнопки могут переноситься.
- Доска, аналитика, карточка и CSV-окно не создают переполнения страницы на 320 px. График аналитики сохраняет собственную намеренную прокрутку.
- Эмодзи в видимом тексте доски и профиля не обнаружены; UI использует иконки.
- ML: проверены обязательный/желательный/не требующийся контекст, совпадение личного навыка, отсутствие контекста, блокировка при пустом описании и скрытие результатов после изменения ввода.
- Анализ не меняет навыки карточки; тестовые изменения выполнялись только в локальном демо и не сохранялись в личном аккаунте.
- Ошибок в консоли проверенной локальной вкладки нет.

Проверки кода: 45 Node-тестов, 6 Python-тестов, TypeScript и production build. Прогнозы JS совпадают со всеми 24 прогнозами Python из сохранённого отчёта. Это проверка переноса модели, не независимое подтверждение качества на реальных вакансиях.

На хостинг эта версия ещё не опубликована: требуется согласие владельца на коммит. Настройки доступа не изменялись. Реальные клавиатуры мобильных устройств, доставка кода и загрузка файлов на физических телефонах в этой проверке не тестировались.
