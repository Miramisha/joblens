## Полный сценарий аккаунта и тестовый runtime

Предыдущий запуск через Wrangler API по-прежнему возвращал 503 `Your worker restarted mid-request`. Тесты переведены на прямой запуск собранного Worker в Miniflare без dev-прокси и реестра Wrangler, с той же локальной D1 и статическими ресурсами. Прикладные POST-запросы не повторяются автоматически.

Добавлен `account-lifecycle-smoke.py`: подтверждение кода из локальной фикстуры, изменение профиля, создание и изменение вакансии, выход, повторный вход, проверка сохранности, экспорт, удаление вакансии, восстановление истории/заметок, отсутствие дубликатов при повторном импорте и отзыв сессии после выхода. Настоящее письмо и личные данные владельца не используются. Проверка аккаунта в production всё ещё требует настройки почты; это не считается пройденным тестом настоящего входа.
