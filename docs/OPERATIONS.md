# Эксплуатация JobLens

## Резервная копия и восстановление

В профиле скачайте JSON-копию и храните её в своём защищённом хранилище. Файл содержит персональные заметки и почту. Это ручная пользовательская копия, а не автоматический бэкап всей D1.

Восстановление принимает формат `joblens-account-export`, version 1, только для той же почты, до 5 МБ и 100 вакансий. Сервер проверяет поля, URL, историю и даты. Имя/навыки обновляются; вакансии добавляются без перезаписи существующих. Повторная загрузка того же исходного файла не создаёт дубликаты. Изменённые после экспорта существующие карточки не откатываются. Коды, сессии, права доступа и токены интеграций не восстанавливаются.

После `pnpm build` запустите `python3 tests/run-integration.py`: проверка создаёт временную локальную базу в `.wrangler`, запускает тестовый Worker на порту 3001 и удаляет базу после завершения. Личный аккаунт и производственная база не используются. Эти же сценарии включены в GitHub Actions. Возможность аварийного восстановления всей производственной D1 средствами провайдера в этом проекте не подтверждена. Не обещать срок хранения резервных копий без проверки настроек хостинга.

## Проверка доступности

GET `/api/health` выполняет SELECT 1 в D1. 200 означает доступную базу, 503 — сбой. Ответ не содержит секретов и данных пользователей. При сбое записывается идентификатор инцидента без SQL и персональных данных. Это проверка базы, а не проверка доставки писем или hh.ru.

Внешний мониторинг с уведомлениями пока не подключён. Для расследования ошибок доступны журналы Worker через Sites. Не сохраняйте тела писем, коды, ключи и заметки в журналах.

## Ограничение входа

`ALLOWED_LOGIN_EMAIL` — единственная почта для выдачи и проверки кодов. Пустая настройка закрывает выдачу/проверку. Установить её отдельно в защищённых переменных хостинга; адрес не коммитить. Это не меняет аудиторию публичного демо и не отзывает уже существующие сессии других пользователей.

## Очистка

См. MAINTENANCE.md. Обработчик готов, но внешний планировщик и контроль его ошибок не подключены. Отсутствие планировщика не продлевает срок действия кода.
